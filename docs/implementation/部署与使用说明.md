# 高拍仪扫描件矫正服务：部署与使用说明

服务对上传的扫描件自动做：纸张检测与透视矫正 → 去倾斜 → 90° 方向矫正（证据充分时修正倒置）→ 裁黑边与多余背景。纯 OpenCV + numpy 实现，不含模型，Python 3.8。

部署流程：**部署机器（联网）安装验证并打离线包 → 拷到现场服务器（不联网）离线安装**。

## 工程文件

| 文件 | 说明 |
|------|------|
| `app.py` | FastAPI 服务：页面、两个处理接口、健康检查 |
| `image_processor.py` | 核心算法，文件头部集中了可调参数；也可命令行单独运行 |
| `static/index.html` | 上传对比页面，不依赖 CDN |
| `requirements.txt` | 固定版本依赖，打包和安装都以它为准 |
| `scripts/build_offline.sh` | 在联网机器上制作离线包 |
| `scripts/install_offline.sh` | 在现场服务器上离线安装（由 build 脚本放进离线包） |

## 一、环境要求

| 项目 | 要求 | 检查命令 |
|------|------|----------|
| 操作系统 | Linux x86_64 / aarch64，glibc ≥ 2.17（CentOS 7 及以上） | `uname -m`、`getconf GNU_LIBC_VERSION` |
| Python | **3.8**，离线包里的 wheel 都是 cp38 | `python3.8 --version` |
| 端口 | 默认 8000 | `ss -tlnp \| grep 8000` |

**部署机器与现场服务器的 CPU 架构必须一致，现场必须已装 Python 3.8**（离线包不含 Python 本身）。现场没有 3.8 时，需在同版本联网机器上下载系统安装包带进去，例如 CentOS 7 用 `yumdownloader --resolve rh-python38`。



## 二、部署机器：联网安装并验证效果

```bash
cd /opt/image-process            # 放工程代码的目录
python3.8 -m venv venv
venv/bin/python -m pip install --upgrade pip
venv/bin/python -m pip install -r requirements.txt   # 慢可加 -i https://pypi.tuna.tsinghua.edu.cn/simple
venv/bin/python -m pip check
venv/bin/python -c "import app; print('OK')"

# 前台启动（必须在工程目录下启动）
venv/bin/python -m uvicorn app:app --host 0.0.0.0 --port 8000
```

浏览器打开 `http://<IP>:8000/`，上传真实扫描件：左侧是原图（绿框为检测到的纸张边界），右侧是处理结果，下方显示旋转角度、倾斜角度、方向置信度和执行步骤。效果不理想时见第七节调参。

不启动服务、只测算法：

```bash
venv/bin/python image_processor.py 输入.jpg 输出.jpg     # 打印处理元数据
```

## 三、部署机器：打离线包并先自测离线安装

```bash
cd /opt/image-process
bash scripts/build_offline.sh                    # 目标 x86_64
TARGET_ARCH=aarch64 bash scripts/build_offline.sh # 目标 ARM（鲲鹏/飞腾）
# 用镜像：PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple bash scripts/build_offline.sh
```

脚本用 `pip download --platform manylinux2014 --python-version 3.8 --only-binary=:all:` 下载目标平台的 wheel，并额外带一个兼容 3.8 的 pip wheel。产物：

```
dist/image-process-offline.tar.gz          # 离线包
dist/image-process-offline.tar.gz.sha256   # 校验值
```

包内结构：`install_offline.sh`、`BUILD_INFO.txt`、`requirements.txt`、`offline_packages/`（wheel + SHA256SUMS）、`app/`（代码、页面、文档）。

**拷到现场前，先在部署机器上用离线包装一遍**，安装全程使用 `--no-index`，不会访问网络，能装成功就说明离线包完整：

```bash
cd /tmp && tar -xzf /opt/image-process/dist/image-process-offline.tar.gz
cd image-process-offline
INSTALL_DIR=/tmp/imgproc-verify SMOKE_PORT=18000 bash install_offline.sh
```

看到 `冒烟测试通过：GET /health 返回 status=ok` 和 `安装完成` 即可。验证完删除 `/tmp/imgproc-verify` 和 `/tmp/image-process-offline`。

打包失败的常见原因：

| 报错 | 处理 |
|------|------|
| `No matching distribution found for xxx==版本` | 该版本没有 Linux/cp38 的 wheel，调整 `requirements.txt` |
| `存在非 wheel 文件` | 有依赖只提供源码包，需换版本 |
| `构建机 pip 版本过旧` | `python -m pip install --upgrade pip` |

## 四、现场服务器：离线安装

把 `.tar.gz` 和 `.sha256` 两个文件一起拷过去（U 盘/摆渡系统；限制单文件大小时用 `split -b 50M` 分卷，到现场后 `cat *.part-* > image-process-offline.tar.gz` 合并）。

```bash
cd /tmp
sha256sum -c image-process-offline.tar.gz.sha256      # 期望 OK
tar -xzf image-process-offline.tar.gz
cd image-process-offline
sudo bash install_offline.sh 2>&1 | tee install.log
```

可选环境变量：

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `INSTALL_DIR` | `/opt/image-process` | 安装目录；无 sudo 时设为 `$HOME/image-process` |
| `PYTHON_BIN` | 自动查找 `python3.8`、`python3` | 如 `/opt/rh/rh-python38/root/usr/bin/python3.8` |
| `SKIP_SMOKE_TEST` | `0` | 设为 `1` 跳过安装后的临时启动检查 |
| `SMOKE_PORT` | `18000` | 临时启动检查的端口（只监听 127.0.0.1） |

脚本步骤：检查架构/glibc/Python 3.8 → 校验 wheel 的 SHA256 → 复制代码（已有旧版本时备份到 `INSTALL_DIR/.backup/<时间>/`）→ 创建 venv（缺 ensurepip 时用包内 pip 引导）→ 离线安装依赖 → `pip check`、逐个导入、`import app`、临时启动请求 `/health`。

## 五、后台运行（systemd）

```bash
sudo useradd --system --no-create-home --shell /usr/sbin/nologin imgproc
sudo chown -R imgproc:imgproc /opt/image-process
```

`/etc/systemd/system/image-process.service`：

```ini
[Unit]
Description=Image Process Service
After=network.target

[Service]
Type=simple
User=imgproc
Group=imgproc
WorkingDirectory=/opt/image-process
ExecStart=/opt/image-process/venv/bin/python -m uvicorn app:app --host 0.0.0.0 --port 8000 --workers 2
Restart=on-failure
RestartSec=5
NoNewPrivileges=true
PrivateTmp=true

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now image-process
sudo systemctl status image-process
sudo journalctl -u image-process -f
```

`--workers` 一般取 CPU 核数，每个 worker 是独立进程，处理大图时各自占内存。防火墙放行：`firewall-cmd --permanent --add-port=8000/tcp && firewall-cmd --reload`（CentOS）或 `ufw allow 8000/tcp`（Ubuntu）。

健康检查（内网常配有 `http_proxy`，请求本机要加 `--noproxy '*'`）：

```bash
curl --noproxy '*' -s http://127.0.0.1:8000/health
# {"status":"ok","version":"1.0.0"}
```

需要 Nginx 反向代理时，设置 `client_max_body_size 12M;` 和 `proxy_read_timeout 120s;`，uvicorn 改为只监听 `127.0.0.1`。

## 六、接口说明

上传限制 10MB（`app.py` 中 `MAX_UPLOAD_SIZE`）。输入支持 JPEG/PNG/BMP/TIFF/WebP，JPEG 的 EXIF 方向会自动应用。

### 请求参数（两个处理接口相同，均为 `multipart/form-data`）

| 参数 | 默认 | 说明 |
|------|------|------|
| `file` | 必填 | 图片文件 |
| `detect_document` | `true` | 检测纸张边界并透视矫正 |
| `deskew` | `true` | 去除小角度倾斜 |
| `fix_orientation` | `true` | 自动 90° 方向矫正 |
| `trim_borders` | `true` | 未检测到纸张时裁黑边、裁到内容区域（留 2% 页边距） |
| `manual_rotation` | `0` | 自动处理后再顺时针旋转 0/90/180/270 |
| `output_format` | `JPEG` | `JPEG` 或 `PNG` |
| `quality` | `90` | JPEG 质量 1-100 |
| `debug` | `false` | 仅 JSON 接口：额外返回原图标注检测框的调试图 |

非法的参数值会回退为默认值。

### POST /api/v1/process：直接返回图片

响应体是图片，`Content-Type` 为 `image/jpeg` 或 `image/png`，处理元数据在响应头 `X-Process-Info`（JSON 字符串）。

```bash
curl --noproxy '*' -s -X POST http://127.0.0.1:8000/api/v1/process \
  -F "file=@scan.jpg" -D - -o result.jpg | grep -i x-process-info
```

### POST /api/v1/process/json：返回 JSON

```json
{
  "image": "<base64 图片>",
  "mime_type": "image/jpeg",
  "metadata": {
    "detected_quad": [[x, y], [x, y], [x, y], [x, y]],
    "rotation_applied": 90,
    "deskew_angle": -2.3,
    "orientation_confidence": 0.62,
    "original_size": [4032, 3024],
    "processed_size": [2480, 3508],
    "processing_time_ms": 850.2,
    "steps": ["document_warp", "deskew", "orientation"]
  },
  "debug_image": "<base64，仅 debug=true 时有>"
}
```

| 元数据字段 | 含义 |
|------|------|
| `detected_quad` | 原图中纸张四角（左上、右上、右下、左下），未检测到为 `null` |
| `rotation_applied` | 顺时针旋转角度，含自动与手动 |
| `deskew_angle` | 去倾斜角度，正数为逆时针 |
| `orientation_confidence` | 方向判断置信度 0~1，偏低时建议人工复核或传 `manual_rotation` |
| `steps` | 实际执行的步骤：`document_warp`/`deskew`/`orientation`/`trim`/`manual_rotation` |

Python 调用示例：

```python
import base64, requests
with open('scan.jpg', 'rb') as f:
    r = requests.post('http://服务器:8000/api/v1/process/json',
                      files={'file': f}, data={'output_format': 'JPEG'}, timeout=60)
r.raise_for_status()
data = r.json()
open('result.jpg', 'wb').write(base64.b64decode(data['image']))
print(data['metadata'])
```

错误：400 图片无法解码/为空，413 超过大小限制，500 服务内部错误，响应体为 `{"detail": "原因"}`。

## 七、算法说明与调参

| 步骤 | 做法 | 失败时的表现 |
|------|------|------|
| 纸张检测 | Canny 边缘和 Otsu 亮度两路找四边形；要求面积占画面 20%~97%、四角 50°~130°，且边线内外色差 ≥ 25 | 判为没有纸张边界，跳过透视，走裁边流程 |
| 去倾斜 | 在 ±45°（透视后 ±5°）内搜索文字行列投影能量最大的角度 | 低于 0.3° 或置信度不足时不旋转 |
| 方向 | 行/列投影特征判断横排还是竖排；竖排时根据中文标点在字格下方、行首对齐来决定转 90° 还是 270° | 无法判断时不旋转 |
| 倒置 | 标点证据 ≥ 8 个且明显在字格上方时才转 180° | 默认偏保守，宁可不转 |
| 裁边 | 未检测到纸张时去掉四周黑边，再裁到内容区域 | 内容面积小于 10% 时不裁 |

可调参数在 `image_processor.py` 文件头部，常用的有：

| 参数 | 默认 | 调整方向 |
|------|------|------|
| `MIN_EDGE_CONTRAST` | 25 | 白纸放在浅色底板上检测不到纸边时调低（如 15）；表格外框被误当纸边时调高 |
| `MIN_DOC_AREA_RATIO` | 0.2 | 纸张在画面中很小时调低 |
| `DOC_INSET_RATIO` | 0.004 | 结果边缘残留阴影时调大 |
| `VERTICAL_RATIO` | 1.3 | 横排文档被误转 90° 时调大；竖向未被矫正时调小 |
| `FLIP_180_SCORE` | -0.5 | 倒置未被识别时调高（如 -0.3）；正向被误翻时调低 |

已知局限：
- 90°/270° 和倒置靠标点与对齐等经验规则，纯表格、纯数字、标点很少的页面可能判断错，请结合 `orientation_confidence` 使用 `manual_rotation`。
- 书本弯曲页面只做整体透视，不做曲面展平。
- 纸张与背景颜色接近时检测不到纸边，此时只做去倾斜和裁边。

## 八、升级与回滚

- 部署机器更新代码 → 重新执行 `build_offline.sh` → 现场解压后再次执行 `install_offline.sh`（`INSTALL_DIR` 与上次相同，自动备份旧代码、复用 venv）→ `sudo systemctl restart image-process`。
- 回滚：`sudo cp -r /opt/image-process/.backup/<时间>/. /opt/image-process/` 后重启；若新版本改过依赖，需用旧离线包重新安装一次。

## 九、常见问题

| 现象 | 原因与处理 |
|------|-----------|
| `架构不匹配` | 用 `TARGET_ARCH=aarch64` 重新打包 |
| `未找到 Python 3.8` / `is not a supported wheel on this platform` | 现场 Python 不是 3.8 或架构/glibc 不符；用 `PYTHON_BIN` 指定 3.8 |
| `wheel 校验失败` | 传输损坏，重新拷贝并先 `sha256sum -c` |
| `/usr/bin/env: 'bash\r'` | 脚本带 Windows 换行，未用 build 脚本打包；`sed -i 's/\r$//' install_offline.sh` |
| `已有虚拟环境 … 不是 Python 3.8` | 移走 `INSTALL_DIR/venv` 后重装 |
| `冒烟测试端口 18000 已被占用` | `SMOKE_PORT=18080` 或 `SKIP_SMOKE_TEST=1` |
| `No module named 'app'` | 未在安装目录下启动；检查 systemd 的 `WorkingDirectory` |
| `ImportError: libGL.so.1` | 装成了 `opencv-python`，卸载后重装依赖（应为 headless 版） |
| `Address already in use` | 端口被占用，`ss -tlnp \| grep 8000` |
| curl 本机返回 502 或代理页面 | 加 `--noproxy '*'` |
| systemd 启动后立即退出 | `journalctl -u image-process -n 50`；常见为目录属主不是 `imgproc` |
