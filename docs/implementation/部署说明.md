# 部署说明

## 一、Python 3.8 安装

```bash
# Ubuntu 20.04
sudo apt install -y python3.8 python3.8-venv
# Ubuntu 22.04+
sudo add-apt-repository -y ppa:deadsnakes/ppa && sudo apt install -y python3.8 python3.8-venv
# CentOS 8 / Rocky
sudo dnf install -y python38
# CentOS 7（解释器为 /opt/rh/rh-python38/root/usr/bin/python3.8）
sudo yum install -y centos-release-scl rh-python38
```

## 二、部署机器验证（联网）

```bash
cd /opt/image-process
python3.8 -m venv venv
venv/bin/python -m pip install --upgrade pip
venv/bin/python -m pip install -r requirements.txt
venv/bin/python -c "import app; print('OK')"
venv/bin/python -m uvicorn app:app --host 0.0.0.0 --port 8000
```

浏览器 `http://<IP>:8000/` 上传真实扫描件测试。

## 三、打离线包

```bash
bash scripts/build_offline.sh                    # x86_64
TARGET_ARCH=aarch64 bash scripts/build_offline.sh # ARM
```

产物：`dist/image-process-offline.tar.gz` 和 `.sha256`

**先在部署机器上用离线包装一遍验证完整性**：
```bash
cd /tmp && tar -xzf /opt/image-process/dist/image-process-offline.tar.gz
cd image-process-offline
INSTALL_DIR=/tmp/verify SMOKE_PORT=18000 bash install_offline.sh
```

看到 `安装完成` 即可，验证后删除 `/tmp/verify` 和 `/tmp/image-process-offline`。

## 四、现场离线安装

```bash
cd /tmp
sha256sum -c image-process-offline.tar.gz.sha256
tar -xzf image-process-offline.tar.gz
cd image-process-offline
sudo bash install_offline.sh
```

可选变量：
- `INSTALL_DIR`（默认 `/opt/image-process`）
- `PYTHON_BIN`（自动查找 python3.8，CentOS 7 SCL 需指定路径）
- `SKIP_SMOKE_TEST`（设为 `1` 跳过安装后的启动检查）

## 五、systemd 后台运行

```bash
sudo useradd --system --no-create-home --shell /usr/sbin/nologin imgproc
sudo chown -R imgproc:imgproc /opt/image-process
```

`/etc/systemd/system/image-process.service`：
```ini
[Unit]
Description=Image Process Service
After=network.target

[Service]
Type=simple
User=imgproc
Group=imgproc
WorkingDirectory=/opt/image-process
ExecStart=/opt/image-process/venv/bin/python -m uvicorn app:app --host 0.0.0.0 --port 8000 --workers 2
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now image-process
sudo systemctl status image-process
curl --noproxy '*' http://127.0.0.1:8000/health
```

防火墙：`firewall-cmd --permanent --add-port=8000/tcp && firewall-cmd --reload`（CentOS）或 `ufw allow 8000/tcp`（Ubuntu）

## 七、升级

部署机器重新打包 → 现场解压后再次执行 `install_offline.sh`（`INSTALL_DIR` 与上次相同，自动备份旧代码）→ `sudo systemctl restart image-process`

回滚：`sudo cp -r /opt/image-process/.backup/<时间>/. /opt/image-process/` 后重启

## 八、常见问题

| 现象 | 处理 |
|------|------|
| `架构不匹配` | 用 `TARGET_ARCH=aarch64` 重新打包 |
| `未找到 Python 3.8` | 用 `PYTHON_BIN` 指定 3.8 |
| `wheel 校验失败` | 重新拷贝并先 `sha256sum -c` |
| `No module named 'app'` | 检查 systemd 的 `WorkingDirectory` |
| `ImportError: libGL.so.1` | 装成了 `opencv-python`，卸载后重装依赖 |
| `Address already in use` | `ss -tlnp \| grep 8000` |
| curl 本机返回 502 | 加 `--noproxy '*'` |
