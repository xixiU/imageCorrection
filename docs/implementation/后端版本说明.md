# 后端版本说明

## 两种后端版本

本项目现在支持两种图像处理后端：

### 1. 原始工程版本 (original)
- 完全参考 https://github.com/evibhm/ImageCorrection
- 算法、参数、流程与参考工程完全一致
- 特点：
  - 简单可靠的Canny边缘检测
  - 固定参数（thresh1=60, thresh2=240, dilate=1次）
  - 凸包+多边形拟合获取四边形
  - 透视变换矫正
  - 处理速度快（~160ms）

### 2. 当前优化版本 (current，默认)
- 在原始版本基础上的增强实现
- 特点：
  - 多尺度边缘检测（Canny + Otsu二值化）
  - 动态对比度阈值（面积自适应）
  - 支持去倾斜（投影能量法）
  - 支持方向矫正（笔画方向检测 + 标点位置分析）
  - 支持倒置检测
  - 支持智能裁边
  - 处理功能更全面（~420ms）

## 使用方法

### 1. 命令行测试

**测试原始工程版本：**
```bash
python image_processor_original.py 输入图片.jpg 输出图片.jpg
```

**测试当前优化版本：**
```bash
python image_processor.py 输入图片.jpg 输出图片.jpg
```

**对比两种版本：**
```bash
# 对比两种版本的处理效果
python test_backends.py 输入图片.jpg both

# 只测试原始版本
python test_backends.py 输入图片.jpg original

# 只测试当前版本
python test_backends.py 输入图片.jpg current
```

### 2. 启动Web服务

**使用原始工程版本：**
```bash
export BACKEND=original
python -m uvicorn app:app --host 0.0.0.0 --port 8000
```

**使用当前优化版本（默认）：**
```bash
export BACKEND=current
python -m uvicorn app:app --host 0.0.0.0 --port 8000

# 或者不设置环境变量（默认就是current）
python -m uvicorn app:app --host 0.0.0.0 --port 8000
```

### 3. 查看当前后端

访问健康检查端点：
```bash
curl http://localhost:8000/health
```

返回示例：
```json
{
  "status": "ok",
  "version": "1.0.0",
  "backend": "original"  // 或 "current"
}
```

## 参数说明

### 原始工程版本参数

原始工程版本使用固定的算法参数（与参考工程完全一致）：
- Canny阈值：60, 240
- 膨胀次数：1次
- 多边形拟合系数：0.02
- 不支持去倾斜、方向矫正等高级功能

### 当前优化版本参数

详见 `config.json.example` 和 `image_processor.py` 文件头部。

主要可调参数：
- `MIN_EDGE_CONTRAST`：边缘对比度阈值（默认1.5）
- `MIN_DESKEW_ANGLE`：最小去倾斜角度（默认10.0°）
- `VERTICAL_RATIO`：竖排文字判断阈值（默认1.3）
- `FLIP_180_SCORE`：倒置判断阈值（默认-0.5）

## 适用场景建议

### 选择原始工程版本的情况：
1. 只需要基础的纸张检测和透视矫正
2. 输入图像质量很好，方向正确，无倾斜
3. 追求更快的处理速度
4. 需要与参考工程完全一致的效果

### 选择当前优化版本的情况：
1. 需要全自动处理（包括去倾斜、方向矫正、倒置检测）
2. 输入图像方向不确定
3. 需要处理有倾斜的文档
4. 需要自动裁边功能
5. 追求更高的自动化程度和鲁棒性

## 注意事项

1. 两种后端的参数接口不完全相同：
   - 原始版本只支持基本参数（manual_rotation, output_format, quality, apply_adaptive_threshold）
   - 当前版本支持完整参数（detect_document, deskew, fix_orientation等）

2. 切换后端需要重启服务才能生效

3. 原始工程版本不包含二值化功能，如需二值化可设置 `apply_adaptive_threshold=true`

4. 当前版本默认使用JPEG质量90，原始版本默认95
