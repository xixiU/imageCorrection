## 二、核心算法差异

### 2.1 边缘检测策略

#### **参考工程（evibhm/ImageCorrection）**
```python
# 简单直接的Canny边缘检测
gray = cv2.GaussianBlur(gray, (3, 3), 2.0)
binary = cv2.Canny(binary, thresh1, thresh2, apertureSize=3)
binary = cv2.dilate(binary, kernel, iterations=dilate_iterations)
```
- **特点**：参数可调，用户通过滑块实时调整
- **优势**：简洁清晰，适合教学和演示
- **局限**：依赖手动调参，不同图像需要不同参数

#### **我们的工程**
```python
# 多策略组合：Canny双阈值 + Otsu二值化
# 策略1: 固定阈值 (60, 180)
# 策略2: 自适应阈值 (基于图像中值)
# 策略3: Otsu二值化后找外轮廓
contours.extend(cs)  # 合并多种方法的轮廓
```
- **特点**：自动化、多策略并行、无需人工调参
- **优势**：鲁棒性高，适应不同光照/对比度
- **创新**：参考了evibhm的固定阈值(60,240)，同时保留自适应策略

**结论**：我们吸收了参考工程的稳定参数，但增加了自动化能力。

### 2.2 透视变换实现

#### **参考工程**
```python
def warpImage(image, box):
    # 1. 对4个角点排序
    ordered_box = orderPoints(box)
    # 2. 计算目标矩形尺寸（基于边长）
    maxWidth = max(widthA, widthB)
    maxHeight = max(heightA, heightB)
    # 3. 透视变换
    M = cv2.getPerspectiveTransform(ordered_box, dst_rect)
    warped = cv2.warpPerspective(image, M, (maxWidth, maxHeight))
```
- **实现**：标准透视变换流程
- **错误处理**：尺寸无效时返回原图副本

#### **我们的工程**
```python
def _warp_quad(img, quad):
    # 1. 四边形排序（与参考相同）
    # 2. 向外扩展边界（DOC_INSET_RATIO=-0.005）避免裁掉边缘内容
    quad = _expand_quad(quad, img.shape, expand_ratio=0.05)
    # 3. 计算输出尺寸（保持原始分辨率比例）
    # 4. 透视变换 + 白色填充
    warped = cv2.warpPerspective(img, M, (w, h), 
                                  borderMode=cv2.BORDER_CONSTANT,
                                  borderValue=(255, 255, 255))
```
- **增强**：边界扩展、白色填充（避免黑边）
- **错误处理**：多层验证（面积比、角度、不规则检测）

**差异**：基本流程相同，我们增加了边界扩展和更严格的验证。

```python
def _estimate_skew(gray, max_angle):
```

### 2.5 自适应二值化

#### **参考工程**
```python
def adaptive_thres(img, win, beta):
    # 使用 scipy.signal.correlate2d 计算局部均值
    means = sums / cnts
    binary_img = np.where(img_gray < means * beta, 0, 255)
```
- **优势**：参数可调（窗口大小、beta系数）
- **用途**：最终输出清晰的黑白二值图

#### **我们的工程**
```python
# 提供二值化选项，但默认关闭
if options.binarize:
    # 使用OpenCV自适应阈值
```

- **策略**：使用OpenCV内置方法（更高效）
- **默认**：保留彩色/灰度图，由用户选择是否二值化

**差异**：参考工程强制二值化输出，我们提供可选。

## 七、我们的创新点

### 7.1 算法创新

1. **多策略组合边缘检测**
   - 借鉴参考工程的稳定固定阈值（60,180）
   - 叠加自适应阈值和Otsu二值化
   - 提高不同场景下的检测成功率

2. **不规则四边形识别**
   - 角度检查（60°-120°）
   - 面积比检查（防止缺角纸张）
   - 对边长度差异检查（防止变形）
   - 参考工程未做不规则检查

3. **方向检测算法**
   - 基于文本布局的经验规则
   - 横排/竖排判断（行列投影）
   - 倒置判断（标点位置、行首对齐）
   - 置信度评估
   - **参考工程完全不提供**

4. **去倾斜算法**
   - 水平投影能量搜索
   - 自适应角度范围（±5° vs ±45°）
   - 置信度评估（峰值/中位数比值）
   - **参考工程完全不提供**

5. **边界扩展策略**
   - 透视前向外扩展5%（DOC_INSET_RATIO=-0.005）
   - 避免裁掉纸张边缘内容
   - 参考工程未做边界扩展

### 7.2 工程创新

1. **配置外部化**
   - config.json动态覆盖默认参数
   - 现场调参无需改代码、无需重启服务

2. **离线部署方案**
   - 自动打包脚本（支持x86_64/aarch64）
   - 一键安装脚本
   - systemd服务配置

3. **双接口设计**
   - `/api/v1/process`：直接返回图片（适合图片预览）
   - `/api/v1/process/json`：返回JSON（适合前端处理、元数据提取）

4. **调试模式**
   - 返回标注检测框的调试图
   - 返回多张中间图（edges、contours、text_mask）
   - 方便问题诊断与参数调优
